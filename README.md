# UniteCore — Redesigned Vue CLI Website

## Design
- UniteCore orange + white visual system with dark technology sections
- Full-screen hero with local MP4 technology video and fallback poster
- Responsive navigation and mobile menu
- New capability cards, data/security/analytics sections, consulting matrix, statistics, industries and CTA
- Existing component names preserved

## Run
```bash
npm install
npm run serve
```

## Build
```bash
npm run build
```

## Main component names preserved
HeaderSection, HeroSection, CoreSolutions, DataAvailability, DataSecurity, DataAnalytics, ITConsulting, StatisticsSection, TechnologyPartners, IndustriesSection, AboutSection, VisionMission, CTASection, FooterSection.
